# Tab Tidy

[English](README.md) | **简体中文**

一个零构建依赖的 Chrome Manifest V3 标签页管理扩展，用于查找、整理、去重和批量关闭标签页。

## 功能

- 按规范化后的页面标题识别重复标签页并一键清理；保留最近访问的重复页，优先关闭较早且未激活的副本。仅当访问时间相同时，才用活动和固定状态决定保留项。
- 展示所有 Chrome 窗口中的标签页，支持三种视图：
  - **默认：** favicon + 标题前 10 个字符。
  - **仅标签：** 高密度 favicon 网格，悬停显示完整标题。
  - **标签 + 标题：** 详细列表。
- 按标题或网址实时搜索。
- 选择单个标签或全选搜索结果，并批量关闭。
- 点击任意标签卡片，聚焦对应 Chrome 窗口并激活标签页。
- 将标签卡片拖到另一个窗口分组即可移动，目标窗口已折叠时同样可用。
- 每个浏览器窗口都可以独立折叠和展开。
- 打开插件时自动定位并短暂高亮当前活动标签。
- 使用快捷键打开插件或切换到上一个使用的标签页；连续触发可在最近两个标签之间快速往返。
- 根据 Chrome 界面语言自动显示英文或简体中文。

## 快捷键

点击插件顶部的 **快捷键** 按钮，会打开 Chrome 原生快捷键管理页。可分别配置 **激活此扩展** 和 **切换到上一个使用的标签页**。Chrome 不允许扩展直接修改用户快捷键。

## 从源码安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 开启右上角 **开发者模式**。
3. 点击 **加载已解压的扩展程序**。
4. 选择本仓库目录。

## 去重规则

标题会先进行 Unicode 归一化、合并多余空白并忽略大小写。空标题不会参与去重。规范化标题相同即视为重复，不要求 URL 相同。

Chrome 没有向扩展提供标签页创建时间，因此 Tab Tidy 使用 Chrome 的 `lastAccessed` 作为可可靠获得的“最近”标准。

## 隐私

Tab Tidy 只在 Chrome 本地处理标签页元数据，不会把浏览数据发送给外部服务。
